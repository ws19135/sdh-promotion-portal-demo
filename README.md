# Promotion ERP Portal 示範頁

這是一個**純示範**頁面，讓同事免登入、直接看到「登入後」的 Portal 長什麼樣子。

## 先知道這幾件事

- **資料全是虛構的**：案件、需求、創作者、公司名稱、Email 都是示範用；Email 一律是 `example.test`。
- **不連任何系統**：頁面不會對外送出任何網路請求，不接後台，也不接任何公司或客戶資料。
- **唯讀**：所有會「建立、核准、轉專案、記錄報價、確認合作」的按鈕都能按，但只會跳出「這是示範版（唯讀）」的提示，什麼都不會儲存。
- **不能寄信**：「開啟 Email」「複製邀約內容」只是示範畫面，不會開啟信箱，也不會寄出任何信件。
- 頁面上方一直有「示範版｜虛構資料｜唯讀」標示。

## 可以逛什麼

- 總覽：今天的重點、需要處理的需求。
- 需求：59 筆虛構需求，有「待審核／審核中」篩選與「載入更多」，點進去看審核頁。
- 合作推廣：3 個虛構案件（確認合作、候選池、已收到報價），含媒合進度、邀約、報價、合作費用與執行結案。

## 怎麼開

直接用瀏覽器開啟 `index.html` 即可（單一檔案，不需要安裝任何東西）；放到 GitHub Pages 也一樣。
